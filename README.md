# GraphPath-FID

GraphPath-FID evaluates misconception-conditioned behavioral updates in LLM-based student agents. It tests whether assigned mathematical error rules appear at initialization, persist across independent items and dependency paths, respond to targeted feedback, and affect previously correct non-target behavior.

| Artifact | Contents |
| --- | --- |
| `data/task_families_v4.json` | 216 synthetic families across eight misconception mechanisms, three operand-size bands and three graph topologies. Development, validation and test each contain 72 families. |
| `DATASET_CARD.md` | Dataset schema, provenance, evaluation splits and limitations. |
| `generation/` | Rule catalog, graph implementation, deterministic generator and oracle validation. |
| `evaluation/` | Prompt construction, feedback conditions and dual-oracle scoring. |
| `results/*.jsonl` | 226,800 original response texts from 5,040 experimental jobs, split by model and track. |
| `results/provenance.json` | Dataset hashes and a file index with track, model, counts and checksums. |
| `results/README.md` | Response record schema and experiment stage mapping. |

## Validate and score

Run from the repository root with Python 3.10 or later. Dataset validation and response scoring use the standard library.

```sh
python benchmark.py validate
python benchmark.py score inverse_as_same-000 root examples/root_response.json
```

The example response matches the standard oracle. For custom evaluation, use `evaluation.protocol.build_trial` to construct prompts and `score_trial` to score parsed JSON responses. Send only the constructed system and user messages to the evaluated model. The task file also contains the answer keys.

## Original experiment responses

The ten response files cover both experiment tracks and the 72 test families used in the paper. Each file contains the response text as recorded in the experiment ledger, including responses that could not be parsed. See [the response documentation](results/README.md) for the call schedule and field definitions.

The evaluation module supports building individual prompts and scoring JSON answer objects. A full rerun also requires the stateful experiment runners, model providers, and original component integrations. In the original runs, component adapters parsed and validated their native response formats before scoring.

## Regenerate the dataset

Obtain the source archive separately from the [Eedi competition](https://www.kaggle.com/competitions/eedi-mining-misconceptions-in-mathematics). The generator reads the label mapping and calculates label support counts from the archive to ground the eight mechanisms. Prompts and oracle values are generated by GraphPath-FID.

```sh
python benchmark.py regenerate /path/to/eedi-mining-misconceptions-in-mathematics.zip
```
